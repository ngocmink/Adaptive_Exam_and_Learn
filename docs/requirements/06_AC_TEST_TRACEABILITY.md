## Using this with the group report

1. Start a requirements section with a function ID and its value to the user.
2. Describe its UCs with actors, triggers, flows and outcomes.
3. List the child stories and numbered AC IDs.
4. Select a criterion in the forward table to retrieve its exact planned cases.
5. When a test fails, use the reverse table to identify the affected criterion, story, UC and function.
6. Record execution status, actual result, tested commit and defect separately; never equate a traceability link with a passed test.
